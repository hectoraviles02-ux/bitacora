# Bitácora de un operador

Reglas que nacen de incidentes, guardias que las hacen cumplir, y agentes de IA
trabajando en producción real. Una entrada por día — el rastro se deja, no se
reconstruye.

Quien escribe opera sistemas institucionales de reportes en México: pipelines
diarios, bases de datos grandes, directivos esperando un correo a las 8 de la
mañana. Sin laboratorio, sin benchmark: lo que se rompe aquí, se rompe de
verdad. Las reglas de trabajo (44 al día de hoy) existen porque cada una costó
un incidente con fecha.

**La regla de esta bitácora:** cada afirmación lleva su medición o se declara
hipótesis. Lo que no se probó, se dice. Los datos institucionales no viajan
aquí — el método sí.
